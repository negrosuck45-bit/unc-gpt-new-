# Public Manus-style design notes

Sources consulted:

- https://manus.im/
- https://manus.im/docs/features/projects
- https://manus.im/docs/website-builder/getting-started

The public Manus homepage emphasizes a single conversational workspace with a simple prompt and task-oriented quick actions. Its Projects documentation describes a persistent workspace sidebar with project creation, task organization, filtering, and recents. The website-builder documentation emphasizes a unified conversational workflow with visible progress and a live preview rather than a collection of disconnected screens.

Design principles for UNC GPT: keep one dominant chat surface; make the sidebar a compact workspace navigator for new chat, recents, projects, and settings; use translucent surfaces sparingly over a dark base; make controls remain tappable while streaming; and use full-screen mobile settings with clear back/close behavior. The redesign should be inspired by these patterns, not copy Manus branding, text, or protected artwork.
